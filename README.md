# 一箭清空 · 微信小游戏 MVP

> 60 秒，找出能安全飞出棋盘的箭头，一路消除、连续清屏、刷新最高分。
>
> 本项目把 `arrow-clear-mvp.md` 的玩法规则实现为**纯本地微信小游戏**，视觉参照 `arrow-clear-preview.html`，核心规则层同时由 Node 单元测试覆盖。

## 当前交付

- **平台**：微信小游戏（`compileType: game`），竖屏，Canvas 2D 绘制。
- **实现说明**：MVP 设计文档面向微信小游戏；本项目直接使用小游戏 Canvas 2D + 原生 WX API 实现，未引入 Cocos 构建链。规则层保持纯 JavaScript，便于独立测试与后续迁移。
- **运行方式**：全部本地运行，不需要服务器、登录、网络请求或外部素材。
- **核心闭环**：首页 → 首次玩法引导 → 60 秒挑战 → 点击箭头 → 飞出/受阻 → 清屏 → 下一关 → 结算 → 再来一局。
- **规则实现**：
  - 4×4 / 5×5 / 6×6 逐关升级，反向构造保证必有合法消除。
  - 点击成功 `+10` 分；每连续成功达到 5 的倍数额外 `+10`；清空一盘 `+50`。
  - 受阻扣 2 秒、连击归零、不扣分；动画期间输入锁。
  - 每局 1 次免费提示，只高亮合法箭头，不改变棋盘与分数。
  - 准确的实际时间计时，暂停/微信退后台不计时。
  - 本地最高分、最高连击、最多清屏与音效开关持久化。
  - 结算展示本局消除数、清屏数、最长连击、受阻次数、NEW BEST / 距离纪录。
  - 分享文案与分享按钮；分享失败不影响继续免费游玩。
- **视觉**：深夜电光风格，Canvas 绘制圆角棋盘、发光提示、飞出/回弹/清屏动效、低时间警示。
- **音效**：包内 5 个极小 WAV，音效开关可关闭；播放失败静默降级。

## 在微信开发者工具中运行

1. 安装微信开发者工具。
2. 导入本项目根目录 `D:\github\clear-game`，项目类型为**小游戏**。
3. `project.config.json` 里当前使用的是供本地测试的小游戏测试号 AppID：`wxe373b7ea958eea6b`。正式发布前请替换为你自己的小游戏 AppID。
4. 点击“编译”即可在模拟器中游玩；无需 npm 构建，也没有网络依赖。
5. 首次启动会显示玩法引导；首次完成后可点“开始 60 秒挑战”。

> 说明：`project.config.json` 中的 AppID 是开发测试号，仅用于本地调试，不代表已具备上线、广告或支付资格。

## 已知边界（MVP 刻意不做）

- 不接入广告、支付、登录、好友榜、服务器或云存档。
- 不实现折线箭头、障碍物、拖拽、关卡选择器。
- 不声称本地存档防作弊；未来做跨用户榜时需要另行设计可信校验。
- 分享是自愿行为，不与奖励或解锁绑定。
